# WILQ — Consultation Booking and Real-Time Queue Management System
**1. Project Summary**

WILQ is a web-based application designed to help student groups book consultation schedules and monitor their queue status. It provides available consultation slots, real-time queue updates, and estimated waiting times to make the consultation process more organized and convenient.

**2. Problem Statement**

The current consultation process can cause long waiting times and confusion because scheduling and queue monitoring are handled manually.

The system aims to address the following problems:

Student groups experience long waiting times due to manual scheduling.
Students are unsure whether their selected time slot is still available or when their turn will come.
Changes caused by delayed, paused, or early-finished consultations are difficult to communicate.
NAS moderators must handle invalid, duplicate, or troll bookings that can disrupt the queue.

**3. Target Users**
 - Student Groups
Log in using their provided shared group credentials.
View available consultation schedules.
Book an available consultation slot.
Monitor their queue position and estimated waiting time.
Receive updated queue information when schedules change.
 - NAS Moderator
View the centralized consultation queue.
Review and remove invalid, duplicate, or troll bookings.
Monitor bookings and queue information.
 - Instructor / Consultation Facilitator
Manage consultation sessions.
Start, pause, resume, and end consultations.
Allow the system to update queue information when session schedules change.

**4. Key Features**
Group Login – Allows student groups to access the system using shared credentials.
Schedule Viewing – Displays available consultation dates and time slots.
Consultation Booking – Allows groups to book available slots while preventing double-booking.
Real-Time Queue Tracking – Displays queue positions and estimated waiting times.
Queue Updates – Adjusts queue information when consultations are delayed, paused, resumed, or ended early.
Queue Moderation – Allows the NAS moderator to remove invalid, duplicate, or troll bookings.
Session Management – Allows the instructor to start, pause, resume, and end consultation sessions.
